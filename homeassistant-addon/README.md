# Home Assistant add-on: UHPPOTE Desk

Manage **UHPPOTE UT0311-L0x** access controllers from Home Assistant OS: doors, people, cards and permissions, live
monitor, attendance, and native Home Assistant entities through MQTT (configured automatically).

![Supports amd64 Architecture][amd64-shield] ![Supports aarch64 Architecture][aarch64-shield]

## Installation

1. *Settings → Add-ons → Add-on store → ⋮ → Repositories*, add `https://github.com/alexbn71/UHPPOTE-Desk`.
2. Install **UHPPOTE Desk**, start it and open the web interface.

See the **Documentation** tab of the add-on for the options, and the
[project page](https://github.com/alexbn71/UHPPOTE-Desk) for everything else.
